## 9. Security & Privacy Checks
- **Secret Masking:** Plaintext client secrets, JWT access keys, and encryption secrets are blocked from API responses and log outputs.
- **Database Error Masking:** General error middleware intercepts database or system failures and returns generic error codes (`code: 'INTERNAL_SERVER_ERROR'`) rather than raw Prisma stack traces.
- **Workspace Scoping:** All metadata, directory creations, and file operations check `req.user.id` or are explicitly scoped to the user session.
- **Option A Reconnect Protocol:** Accounts created with the old scope return `reconnectRequired: true` and are:
  - Blocked from upload selection.
  - Flagged in the UI with a red warning badge `⚠️ Reconnect Required`.
  - Allowed self-service reconnection via a **Reconnect** button.

## 10. Manual OAuth Verification Checklist

When checking with a physical Google account in production, use the following manual checklist:

- [ ] **Configure Test Users:** Ensure that the test Gmail account is registered under **Google Cloud Console > OAuth Consent Screen > Test Users** if the Google app status is still in "Testing" mode.
- [ ] **Trigger Connect Flow:** Go to the CasaNest Settings page, and click **Connect Drive** (or **Reconnect** on an existing connection).
- [ ] **Verify Consent Screen Details:** In the Google OAuth popup, verify that:
  - The application name matches your configured registration.
  - The requested permission is **"See, edit, create, and delete only the specific Google Drive files you use with this app"** (restricted `.file` scope), **NOT** full drive access.
- [ ] **Authorize Account:** Accept permissions and allow redirection.
- [ ] **Confirm UI Callback:** The popup should close automatically, and the connected account should display on the settings dashboard.
- [ ] **Smoke Test Uploads:** Upload a small text file through the dashboard. Verify that it appears in your Google Drive inside the `casanest` folder.
- [ ] **Confirm Privacy Boundary:** Confirm that preexisting files located elsewhere in your Google Drive do **not** sync or appear inside the CasaNest workspace.
